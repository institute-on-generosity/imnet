# 0014 Posts follow LinkedIn's UI, minus engagement counts
**Status:** accepted, 2026-10-13. Supersedes 0013 for post actions.

Post cards copy LinkedIn: header (logo, name, "N followers", type • time • Edited • public globe, "+ Follow", "⋯" menu with Copy link and Report), text with an inline "…more", media, then a labeled action bar (Moved · Comment · Share · Save). Comment opens the thread inline: a rounded "Add a comment…" box (staff tap their avatar to comment as the org), comments newest first in gray bubbles with name, headline (bio) and time, Reply and Delete under each, replies nested one level, the org's replies marked "Author", "Load more comments".

**Why:** the owner asked for posts modeled on LinkedIn completely; donors already know that layout.
**Not copied:** the reaction/comment/repost counts row and comment likes. Public engagement counts break design principle #4 (no dark patterns). Follower counts were already public on profiles, so the header shows them.
