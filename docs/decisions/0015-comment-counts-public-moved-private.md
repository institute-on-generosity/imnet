# 0015 Comment counts are public; "moved" counts stay private
**Status:** accepted, 2026-10-14. Amends 0014.

The post action bar shows a number next to Comment for everyone, and a number next to Moved only for the post's author, its org's staff and admins (`post_counts()`, F-094).

**Why:** the owner asked for numbers next to Moved and Comment. Comments are already public, so their count reveals nothing new and tells readers there's a conversation. A public "moved" total would work like a like count, which principle #4 (no dark patterns) rules out; the author still gets the encouragement.
**Not done:** public moved counts, follower-style popularity ranking, counts on comments.
